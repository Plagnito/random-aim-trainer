Aim Trainer 3D

Le dojo néon pour muscler ta visée.

Le but : toucher un maximum de cibles avant la fin du temps. Plus tu enchaînes sans rater, plus le multiplicateur grimpe. Ordinateur : la souris est verrouillée, bouge-la pour viser et clique pour tirer. Tactile : touche les cibles et glisse le doigt pour tourner la vue. Choisis un mode pour commencer.

    Comment jouer

    Commandes

    • Souris : bouge pour viser, clic gauche pour tirer (maintiens-le en mode Suivi).
    • Tactile / curseur libre : touche une cible pour tirer, glisse le doigt pour tourner la vue.
    • Échap ou P : pause. R : recommencer. M : couper le son.
    • Une flèche dorée t'indique où est la cible quand elle est hors de l'écran.

    Points

    • Cible touchée : 100 points, 150 si tu touches le centre clair.
    • Combo : +1 de multiplicateur toutes les 5 cibles d'affilée, jusqu'à ×4. Un raté remet à ×1.
    • La difficulté multiplie les points : ×1, ×1,5 ou ×2.
    • Les notes vont de D à S, selon ton score dans le mode.
